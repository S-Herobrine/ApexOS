# SatasOS Pre-Installed & Supported Applications

SatasOS is equipped with an extensive suite of applications across Windows, Android, and Linux ecosystems, ensuring users have everything they need immediately upon installation.

During the Calamares installation process, users can selectively choose their preferred web browsers, office tools, and development suites.

---

## 1. Web Browsers (Installer Multi-Select Choice)

1. **Google Chrome**:
   - The world's most widely used web browser, featuring synchronization with Google Account, Google Password Manager, and Chrome Web Store extensions.
2. **Mozilla Firefox**:
   - Privacy-focused, high-performance browser equipped with enhanced tracking protection, multi-account containers, and open-source rendering.
3. **Microsoft Edge**:
   - Fast, Chromium-based browser with vertical tabs, collections, Microsoft Copilot integration, and seamless Microsoft account synchronization.
4. **Opera Browser**:
   - Feature-rich browser with built-in free VPN, integrated sidebar messengers (WhatsApp, Telegram, Discord), and ad blocker.

---

## 2. Android Subsystem & Google Services (Waydroid)

1. **Google Play Store**: Official app marketplace with access to millions of Android games and productivity applications.
2. **Google Play Services (GMS)**: Full background service framework providing Google sign-in, location services, push notifications, and API safety.
3. **Google Services Framework**: Core Android compatibility services.
4. **Google Account Manager**: Centralized Android authentication manager.
5. **Google Chrome (Android Edition)**: Mobile web browser integration.
6. **Files by Google**: Mobile storage and cleanup manager.
7. **Google Photos**: Cloud photo gallery and backup.
8. **Google Maps**: Navigation and location discovery.
9. **YouTube**: Official video streaming app.
10. **Gmail**: Mobile mail client.
11. **Google Drive**: Cloud storage sync.
12. **Google Keep**: Quick note taking and checklists.
13. **Google Messages**: SMS and RCS communication.
14. **Android System WebView**: High performance embedded web browser engine for Android apps.
15. **SatasOS Android Manager**: Native Linux GUI to manage APK installation, Waydroid service toggles, and Android app window settings.

---

## 3. Desktop Productivity & Office

1. **LibreOffice Writer**: Full-featured word processor compatible with Microsoft Word (.docx).
2. **LibreOffice Calc**: Advanced spreadsheet software compatible with Microsoft Excel (.xlsx).
3. **LibreOffice Impress**: Presentation designer compatible with Microsoft PowerPoint (.pptx).
4. **LibreOffice Draw**: Vector graphics and flowcharts creator.
5. **LibreOffice Base**: Relational database frontend.
6. **SatasOS Files**: Windows Explorer styled dual-pane file manager with `C:\` and `D:\` drive mappings.
7. **Document Viewer (Evince)**: Lightweight PDF, PostScript, and TIFF reader.
8. **Text Editor (Gedit / GNOME Text Editor)**: Clean, tabbed plain text editor with syntax highlighting.
9. **Thunderbird**: Professional desktop email, calendar, and contacts client.

---

## 4. Multimedia & Creative Suite

1. **VLC Media Player**: Universal video and audio player supporting every codec and streaming protocol.
2. **GIMP (GNU Image Manipulation Program)**: Advanced photo retouching and graphic design suite.
3. **Inkscape**: Professional vector graphics editor (SVG, AI, EPS).
4. **Audacity**: Multi-track audio recorder and waveform editor.
5. **OBS Studio**: Industry standard screen recording and live broadcasting suite.
6. **Kdenlive / Shotcut**: Non-linear multi-track video editing software.
7. **Rhythmbox / Amberol**: Clean, modern audio player and music library organizer.
8. **Cheese**: Webcam recording and photo capture utility.

---

## 5. Development & Engineering Tools

1. **Visual Studio Code**: Modern source code editor with extensions for Python, C++, Web, and Flutter.
2. **GNOME Terminal**: Tabbed terminal emulator with purple dark theme.
3. **Tilix**: Advanced tiling terminal emulator for multi-pane shell management.
4. **PowerShell (`pwsh`)**: Microsoft cross-platform automation and scripting console.
5. **Git**: Distributed version control system with pre-configured SSH/GPG helpers.
6. **Python 3 & Pip**: Python runtime with essential libraries pre-loaded.
7. **Node.js & NPM**: JavaScript runtime environment for modern web development.
8. **Build-Essential**: GCC, G++, Make, and standard C/C++ compilation toolchains.
9. **Docker Engine & CLI**: Container management platform for server and app development.

---

## 6. Personalization & Desktop Enhancements

1. **SatasOS Widgets (Rainmeter Alternative)**:
   - Floating desktop clock and weather widget.
   - Real-time CPU, RAM, GPU, and Disk utilization meters.
   - Dynamic monthly desktop calendar.
   - Sticky notes and quick task tracker.
   - Desktop media controller synced with PipeWire / MPRIS.
2. **SatasOS Tweaks (Windhawk Alternative)**:
   - Taskbar alignment and height customization.
   - Acrylic blur and transparency adjustment.
   - Window animation speed and easing configuration.
   - Titlebar button layout (Windows right-side vs macOS/Ubuntu left-side).
   - Shell font selector.
3. **SatasOS Theme Switcher**:
   - Instant toggle between SatasOS Dark (Purple Obsidian) and SatasOS Light (Lavender Mist).

---

## 7. System Administration & Utilities

1. **SatasOS Settings**: Android Material-style system settings application.
2. **GNOME System Monitor**: Real-time process manager, resource graphs, and disk monitors.
3. **GNOME Disks**: Partition manager, SMART health monitor, and drive benchmark utility.
4. **GParted**: Advanced disk partition editor for complex disk management.
5. **Archive Manager (File Roller)**: Support for ZIP, 7Z, RAR, TAR.GZ, and ISO archives.
6. **Calculator**: Standard, scientific, financial, and programmer calculator.
7. **Clocks**: World clocks, alarms, stopwatch, and timer.
8. **Screenshot & Screen Recording**: Built-in interactive area snipping tool.
9. **Timeshift**: System restore point creation tool (similar to Windows System Restore).
10. **Startup Applications Manager**: Configure background services and autostart apps.
11. **Log Viewer**: Systemd journal and error inspection tool.
12. **SatasOS Repair & Recovery Utility**: Scripted repair tool to fix broken packages, audio routing, or Android services.
